# Study With Me ⏱️

A minimalist, custom-built study timer application designed to keep track of focus intervals, eliminate distractions, and optimize deep work sessions.

## Features

* **Focus Tracking:** Clean timer interface to manage study and break intervals.
* **Lightweight:** Built with efficiency in mind, running smoothly directly in the browser.
* **Distraction-Free:** Designed specifically to keep you locked in during study blocks.
